## 🎯 What is Zepruv?

Zepruv is a **collaborative technical Interview Operating System** — built to eliminate the chaos of switching between 6+ tools during interview prep.

> Run a full mock interview — video, code, system design, AI copilot, and real-time feedback — **inside a single browser tab**.

---

## 🏗️ Platform Architecture

| Layer | Technology |
|---|---|
| **Candidate Frontend** | React + Vite + shadcn/ui + Tailwind |
| **Institute Portal** | React + TypeScript + Vite |
| **Backend Services** | Spring Boot (Java 21) + Microservices |
| **AI Agent** | Python FastAPI + OpenAI |
| **Code Execution** | Node.js + Docker sandbox isolation |
| **Real-time Comms** | WebRTC (mesh) + LiveKit SFU + WebSocket signalling |
| **Resume Extraction** | Python NLP service |
| **Infrastructure** | AWS Lightsail + ECR + Cloudflare CDN/Pages |
| **Observability** | Grafana Alloy + Loki + Mimir + Tempo |

## ✨ Platform Features

### For Candidates
- 🎥 **Peer Mock Interviews** — Video + code + whiteboard, all synced
- 💻 **Monaco Code Editor** — Multi-language support with execution (690+ problems)
- 🗺️ **System Design Canvas** — Drag-and-drop architecture diagrams
- 🤖 **AI Interview Copilot** — Real-time feedback, hints, and post-interview reports
- 📊 **Progress Dashboard** — Track performance across sessions
- 🏫 **Campus Mode** — Connect with placement drives at your college

### For Universities & Institutes
- 👩‍🎓 **Bulk student management** — Roles, cohorts, placement tracking
- 📅 **Auto-schedule interviews** — Faculty-driven drive scheduling
- 📋 **Audit logs & reports** — Full visibility on student readiness
- 🔐 **MFA + RBAC** — Secure multi-role access

## 🛡️ Security & Quality

All repositories follow enterprise CI/CD standards:

- **CVE audits** — npm/pip dependency audits on every push
- **Code quality** — ESLint + static analysis gates
- **Container scanning** — Docker image vulnerability scans
- **Branch protection** — PRs required for `develop`, `test`, `main`

## What is Zepruv?

Zepruv is an **Interview Operating System**: the whole interview stack in one tab. Run a full mock interview, with video, code, system design, an AI interviewer and real-time feedback, without switching between tools.

### For candidates
- 🎥 **Peer mock interviews**: video, code and whiteboard, all in sync
- 🤖 **AI interviewer**: a spoken interview with feedback and a report afterwards
- 💻 **Live code editor**: run code in many languages, with hundreds of practice problems
- 🗺️ **System design canvas**: draw and explain your architecture
- 📊 **Progress dashboard**: see how you improve across sessions
- 🏫 **Campus mode**: join the placement drives at your college

### For universities and institutes
- 👩‍🎓 **Student management**: cohorts, roles and placement tracking
- 📅 **Interview scheduling**: schedule interviews with faculty or the AI interviewer
- 📋 **Reports**: see how ready your students are
